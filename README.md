# Honors Chemistry Unit 3 & 4 Exam Prep

A local-first study studio with interactive lessons, chemistry practice labs, flashcards, and a randomized mock exam. No account or backend is required; progress is saved in this browser.

## Run locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Verify a production build with `npm run build`, or serve it with `npm run preview`.

## Study tools

- Nine topic lessons across atomic structure, spectra, electron configurations, PES, VSEPR, and periodic trends.
- Randomized mixed-topic quizzes and a 100-question review bank.
- Wavelength/frequency calculations, configuration typing, and orbital filling-rule simulator.
- Interactive PES peak interpretation, molecular geometry challenge, matching, and periodic-trend ranking.
- Flashcards with local spaced-review scheduling.
- A randomized 50-question mock exam with timed mode, score summary, and missed-question review.
- XP, levels, achievements, streaks, mastery, and light/dark mode saved locally.

Progress lives in local storage on this device. Clearing site data resets it.
